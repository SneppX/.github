# Component Maturity Taxonomy

Status values used across SneppX:

- Planned: designed but not implemented.
- Experimental: implemented, unstable, may change.
- Implemented: code exists, basic functionality.
- Tested: has meaningful automated tests.
- Supported: tested, documented, stable public API.
- Deprecated: scheduled for removal.
- Disabled: present but off by default.
- Unsupported: not supported on this platform.

Do not mark a component Supported without test evidence.
