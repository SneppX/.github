# SneppX Organization

Open-core AI ecosystem built around the [`sneppx-alg`](https://github.com/SneppX/sneppx-alg)
framework.

Organization profile: [profile/README.md](profile/README.md).

## Repositories
- [sneppx-alg](https://github.com/SneppX/sneppx-alg)  — Universal open-source AI algorithm framework (C/C++ & CUDA + Python bindings)
- [linux](https://github.com/SneppX/linux)  — Linux kernel source tree (fork, kept for systems work)
- [.github](https://github.com/SneppX/.github)  — This repository: organization profile and defaults

## What's in this repo
- `profile/README.md`  — Rendered on https://github.com/SneppX
- Community-health files (org-wide): `SECURITY.md`, `CODE_OF_CONDUCT.md`,
  `SUPPORT.md`, `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`
- `CONTRIBUTING.md`, `SPONSORING.md`, `LICENSE`, `FUNDING.yml`
- `.github/workflows/`  — Default workflow templates for repositories that explicitly add them
  (lint, secret scan, license check)
- `CODEOWNERS`  - " review ownership for **this** repo only (CODEOWNERS is per-repo,
  not org-wide)
